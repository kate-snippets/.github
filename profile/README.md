# Kate - Edit Text You Meant to Change

![Kate with a text file the user saved in their own folder](https://docs.kde.org/trunk_kf6/en/kate/kate/snippets-usage.png)

## Product Snapshot

Kate is a text editor for source and notes you write. Several documents can sit in one session. Syntax coloring follows the filetype. Search and replace work on the file you opened. A replace-all across a config you have not copied is how that config disappears.

Use a project folder you can explain. Do not edit files under Windows to see what happens. If a snippet inserts a command, read it before you run it. Kate will not grant you a repository you were not given, and it will not decrypt a file you cannot already open as text.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Documents | Files you open and save |
| Session | Those files gathered for the next launch |
| Search | A find inside the file you chose |
| Snippets | Text you stored on purpose |
| Terminal | A prompt, only if you open it |
| Project | A directory that is yours |

The terminal is optional. The first hour can be editing only. A command in that panel is the same as a command typed anywhere else.

## Deep Dive

Create a file, save it, and change one line you can check. Reopen the session. If the line is missing, you saved somewhere else or not at all. Copy a config before you replace a word that appears many times.

Plugins and extra tools can wait. A session full of other people's documents is a session to close. On a shared PC, exit Kate so the next person does not inherit your files on screen. Back up the project folder. The editor is not the archive.

## Adoption Paths

Kate fits a script, a readme, or a handful of configs you maintain. It fits someone who wants the files as plain text. It does not fit a binary you should not be editing, a system directory, or a snippet you do not understand.

## Install Walkthrough

Prerequisites: A folder of your own text, and no plan to edit Windows itself.

1. Install Kate and open that folder.
2. Save a new file there and type a few lines.
3. Close and reopen the session to confirm the save.
4. Use replace only after you have a copy of the file.
5. Leave the terminal closed until you mean to run a command you have read.
